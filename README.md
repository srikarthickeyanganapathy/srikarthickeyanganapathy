**Deep learning pipeline for spectral super-resolution & crop analysis**

`Python` `PyTorch` `GAN` `XGBoost` `Computer Vision`

- Developed a **Conditional GAN** (ResNet Generator + PatchGAN Discriminator) for RGB → 224-band hyperspectral reconstruction
- Engineered **physics-aware loss functions** — L1 + Spectral Angle Mapper (SAM) + Gradient + Vegetation Index (NDVI/PRI/NDRE)
- Built a **dual-stream disease detection CNN** with SE-attention combining spatial and spectral branches
- Implemented **synthetic disease injection** (chlorosis, water stress, early blight) to solve the "Healthy Bias" problem
- Created a **multi-output classification pipeline** — XGBoost predicts crop name and growth stage from reconstructed spectra
- Trained on **USDA Proximal Hyperspectral Dataset** (160 samples, 224 spectral bands, 400–1000nm)
