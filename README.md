* **[Smart Agriculture Monitoring System (SAMS)](https://github.com/srikarthickeyanganapathy/Smart_Agriculture_Monitoring_System)**

  * Microservices platform for agricultural analytics using Spring Boot, React, and MySQL
  * Designed REST APIs for sensor ingestion and analytics services
  * Integrated Python services for crop health prediction
  * Optimized MySQL schema for scalable field data storage
  * Live: [https://smart-agri-tech-sams.netlify.app](https://smart-agri-tech-sams.netlify.app)

  * Live: [https://tasksflowstf.netlify.app/login](https://tasksflowstf.netlify.app/login)
